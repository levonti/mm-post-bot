# Web UI i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize the web UI using the existing bot locale preference and add an authenticated language switcher.

**Architecture:** Reuse `src/mm_post_bot/i18n.py` as the single catalog. Resolve the web locale in `src/mm_post_bot/web/routes.py`, pass a `t()` helper to templates, and persist switcher changes through `UserPreferenceRepo`.

**Tech Stack:** FastAPI, Jinja2, existing PostgreSQL repositories, pytest.

### Task 4: Route Locale Context And Switcher

**Files:**
- Modify: `src/mm_post_bot/web/routes.py`

- [ ] **Step 1: Add shared helpers**

Add helpers that resolve locale, translate `web.*` keys, and build template context with
`locale`, `supported_locales`, `current_path`, and `t`.

- [ ] **Step 2: Add `/language` route**

Add authenticated POST `/language` route protected by `require_csrf`. It normalizes `locale`,
stores it through `UserPreferenceRepo.set_locale`, and redirects to a safe local `next` path.

- [ ] **Step 3: Localize HTTP errors**

Use the resolved locale for web validation errors where a session exists. Use default locale for
unauthenticated login errors.
